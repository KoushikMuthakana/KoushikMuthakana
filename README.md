## 👋 About Me

I'm a **Senior Data Engineer** based in **Berlin, Germany** with **9+ years** of experience designing and owning large-scale data platforms across AWS, Azure, and GCP.

I specialize in building systems that are **reliable, observable, and built to scale** — from batch pipelines to real-time streaming architectures processing millions of events daily.

- 🏗️ **Batch · Streaming · NRT pipelines** — architecting end-to-end data flows at scale
- 🔄 **Event-Driven Architecture** — Kafka, Kinesis, Spark Structured Streaming, CDC
- 🏛️ **Platform migrations** — cloud consolidation, cost optimisation, disaster recovery
- 📊 **Data Observability** — SLIs/SLOs, anomaly detection, schema contracts, Great Expectations
- 🧠 **LLM integrations** — natural language to SQL, LangChain, online feature stores
- 🌐 **Multi-cloud delivery** — Data Mesh, Medallion Architecture, Lakehouse patterns

- 🔭 **Currently working on:** Event-Driven learner data platforms & personalization systems
- 🌱 **Learning:** Advanced German 🇩🇪 (A1 → B2 journey)
- 💬 **Ask me about:** Kafka, PySpark, Delta Lake, Data Governance, DynamoDB feature stores
